# قصر الرسائل | الريم

موقع عربي تفاعلي للتأمل والرسائل الإيجابية، يتضمن ستة أبواب ورسائل يومية ومشاركة وتقييم الزوار.

## ملفات المشروع
- `index.html`: واجهة الموقع ومنطق الأبواب والرسائل.
- `style.css`: التصميم.
- `ratings.js`: اختيار النجوم والتحقق من التعليق وإرسال التقييم بالبريد عبر EmailJS Browser SDK.
- `netlify/functions/ratings.js` و`functions/api/ratings.js`: مسارات خلفية احتياطية/متوافقة مع منصات النشر؛ إرسال التقييم في الواجهة لا يعتمد عليها.
- `assets/`: الصور.

## إعداد البريد — خطوة مطلوبة مرة واحدة
في لوحة EmailJS افتحي القالب `template_zgb2478` ثم:
1. في خانة **To Email** اكتبي بريد الاستلام الثابت: `reemhappyday@gmail.com`.
2. اجعلي **Subject** مثلا: `تقييم جديد لقصر الرسائل`.
3. ضعي في محتوى الرسالة المتغيرات التالية (كل متغير يكتب بين قوسين مزدوجين):
   - `{{rating}}`
   - `{{comment}}`
   - `{{door}}` و`{{door_name}}`
   - `{{created_at}}`
   - `{{language}}`
   - `{{site_name}}`
4. احفظي القالب، وتأكدي من ربط خدمة البريد الصحيحة داخل EmailJS.

مهم: خانة **To Email** من إعدادات القالب يجب أن تحتوي عنوان الاستلام نفسه؛ إرسال `to_email` ضمن بيانات القالب لا يغيّر إعدادات المستلم. كما يجب السماح للموقع باستخدام EmailJS من إعدادات الحساب إذا كان هناك تقييد للنطاقات.

## اختبار الإرسال
بعد اكتمال نشر GitHub/Netlify، افتحي الموقع، اختاري بابا، ثم «تقييم التجربة»، واختاري النجوم واضغطي «إرسال التقييم». تظهر رسالة النجاح عندما يؤكد EmailJS قبول طلب الإرسال؛ افحصي صندوق الوارد والرسائل غير المرغوب فيها.

## النشر
يُستخدم جذر المستودع كمجلد الموقع. لا تحذفي مجلد `assets` أو ملف `style.css`.
